# ThreadForge

Official Windows installers and update files for ThreadForge.

[Download the latest installer](https://github.com/sapixeldevelopment/ThreadForge-Releases/releases/latest)

Download the `ThreadForge-Setup-<version>-x64.exe` asset and run the installer. ThreadForge installs for your Windows user and retains existing workspace data when updating.

In ThreadForge, open **Settings → Updates** to check for new versions, download an update, and choose when to install and restart. The official release source is `https://github.com/sapixeldevelopment/ThreadForge-Releases`.

This repository contains release documentation and downloadable installers, checksums, block maps and update metadata. The application's source repository is maintained separately and is private.

The Windows installer is currently unsigned. Coding provider CLIs and their account authentication are installed separately. Restarting closes active shells; saved conversations reopen, while interrupted commands do not continue automatically.
